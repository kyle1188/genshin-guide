原神Aino（爱诺）Build攻略：4★水双手剑月充能副C

Aino（爱诺）是 6.0 月之一（Luna I）上线的 4★水元素双手剑，挪德卡莱天才发明家。定位月充能水副C，Q 挂水 + 全队精通：丝月小夜曲（Silken Moon's Serenade）4pc + Flame-Forged Insight（双手剑专武）+ 充能沙，是哥伦比娅的免费替代。

快速答案

  • 定位：月充能水副C + 全队精通拐。
  • 武器：Flame-Forged Insight（双手剑专武）＞ 西风大剑（Favonius Greatsword）＞ 渊海砗磲（Makhaira Aquamarine）。
  • 圣遗物：丝月小夜曲 4pc（首选）/ 高贵的义务 / 焚城英雄卷轴。
  • 主词条：充能沙 + 精通杯 + 精通头。
  • 配队：Zibai + Aino + 鹿野院 + 琳妮娅（月结晶）。

Aino 是谁

Aino（爱诺）是 6.0 月之一（Luna I） 上线的 4★水元素双手剑，挪德卡莱的天才发明家、Ineffa 的创造者。定位是月充能（Lunar-Charged）水副C，Q 挂水 + 全队精通增益，是 哥伦比娅的免费替代（4★ 月系挂水）。

最佳武器

以下为核实过的双手剑（括号内为官方英文名）：

武器推荐理由
Flame-Forged Insight（5★双手剑专武）精通副词条 + 回能，Q 增伤吃精通
Favonius Greatsword（西风大剑，4★）副词条暴伤 + 回能，长期可用
Makhaira Aquamarine（渊海砗磲，4★）水伤 + 精通双收益，须弥存量
Master Key（水之钥，4★锻造）精通白值高，F2P

最佳圣遗物

套装效果适用
丝月小夜曲（Silken Moon's Serenade）4pc全队精通（60/120随月兆）+ 月反应增伤 10%/层，挪德卡莱专属首选
高贵的义务（Noblesse Oblige）4pc攻击 + 水伤，通用水辅助备选
焚城英雄卷轴（Scroll of the Hero of Cinder City）4pc攻击 + 全队增伤，副C向备选
教官（Instructor）4pc精通 + 充能，F2P 过渡预算

主词条：充能沙 + 精通杯 + 精通头；副词条 充能 > 精通 > 暴率。

天赋升级顺序

元素爆发（Q）> 元素战技（E）> 普攻。Q 是核心水副C + 全队精通增益（Structured Power Booster 让 Q 增伤吃 50% 精通），E 产球回能，普攻占比低。

队伍成员要点

命座价值（gcsim 模拟）

基线（C0 + Favonius Greatsword）137,264 DPS。C1 +3.1%、C2 +4%、C3/C4 +0%、C6 +10.1%（较 C5 多 +6%）。C6 质变，C1–C4 边际收益低，F2P 抽 0 命即可，有富余再追 C6。

是否值得抽

有哥伦比娅可跳；缺月系挂水 + 全队精通拐、又想省 5★ 资源时 Aino 是低成本高性价比的 4★ 解法，Zibai / Flins 月系队伍刚需。
