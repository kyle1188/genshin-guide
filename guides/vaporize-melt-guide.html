原神蒸发与融化详解：2 倍还是 1.5 倍，触发顺序决定一切

蒸发和融化是原神里最强的两个单段伤害倍率，但它们吃的是你主 C 的面板，不是反应本身。最容易被搞错的是触发顺序：顺序错了，倍率从 2 直接掉到 1.5，伤害砍掉三分之一。这篇把 2×/1.5×、精通加成、弱/强版本一次讲清。

快速答案
  • 蒸发 = 水 + 火；融化 = 冰 + 火。都是增幅反应，放大的是触发那一击的伤害。
  • 2 倍：水打蒸发（火附着上）、火打融化（冰附着上）。叫"强版"。
  • 1.5 倍：火打蒸发（水附着上）、冰打融化（火附着上）。叫"弱版"。
  • 吃主 C 的攻击力、暴击、元素伤加成、精通 —— 和剧变反应完全不同。
  • 精通加成公式：2.78 × 精通 ÷（精通 + 1400），200 精通 ≈ +35%。

一、增幅 vs 剧变：完全不同的两套结算

这是理解蒸发融化的前提。原神反应分两类：

增幅反应（蒸发/融化）剧变反应（燃烧/超载/超绽放…）
伤害来自放大触发的那一击反应本身另算一段伤害
吃面板攻击力、双暴、元素伤、精通只看等级、精通、减抗
能吃暴击能不能
代表角色胡桃、宵宫、雷电、可莉纳西妲、香菱（副）

所以蒸发融化喂给你的主 C才有意义：它是把主 C 那一下高倍率攻击再乘 2。剧变反应则只跟触发者的等级、精通有关，主 C 面板越高它本身伤害越大。两条路是并列的配队哲学，不是谁替代谁。

二、2 倍 vs 1.5 倍：触发顺序表

关键只有一条：后落的那个元素决定倍率，且"强元素"给 2 倍。

反应触发顺序倍率版本
蒸发（水+火）火打水附着1.5×弱版
水打火附着2×强版
融化（冰+火）冰打火附着1.5×弱版
火打冰附着2×强版

规律：蒸发里水是强元素，融化里火是强元素。强元素去触发的版本给 2 倍。所以：

  • 让火主 C打在水/冰挂好的目标上 → 2 倍（宵宫、胡桃的常规玩法）。
  • 让水主 C打在火挂好的目标上 → 2 倍（雷电、夜兰配火辅助的路子）。

这就是"顺序错了少三分之一"的准确含义：你本可以吃 2× 却吃了 1.5×，等于凭空丢掉 25%。

三、精通加成：增幅走单独公式

增幅反应的精通加成 = 2.78 × 精通 ÷（精通 + 1400），和剧变那套（16×精通/(精通+2000)）不一样：

元素精通增幅加成举例：1,000 基础伤 × 2 倍
0+0%2,000
100+18.7%2,374
200+35.0%2,700
400+64.3%3,286
600+83.5%3,670
1000+113.5%4,270

增幅反应既吃主 C 面板、又额外吃精通加成，所以它是"双料"：面板越高、精通越高，数字越大。这也是蒸发融化主 C 普遍要留一部分词条给精通的原因——它乘在整段伤害上，不白给。

四、强版和弱版的隐藏差别：元素量消耗

除了倍率，版本还决定消耗多少附着量：

  • 2 倍（强版）消耗更多附着，容易把目标身上的元素清空，之后要重新挂才能再触发。
  • 1.5 倍（弱版）消耗较少，常留一层元素，可能紧接着再触发一次反应。

所以有时候"吃 1.5 的弱版"反而比"吃 2 的强版"总收益高——因为它不消耗尽元素，能连吃。这是进阶配队时才会精算的点，日常不用逐帧算，但要知道它存在。

五、给蒸发融化主 C 配词条

部位推荐

头暴击率 / 暴击伤害
沙攻击力%

炽烈的炎之魔女对蒸发融化额外 +40% 反应伤害，是增幅流首选套装；如雷的盛怒走另一条反应加成。主 C 本身还是老老实实堆双爆，精通只作为副词条补一点点。

六、常见问题

蒸发融化的伤害是主 C 的吗？

是。增幅反应放大的是触发那一击，吃主 C 的攻击、暴击、元素伤。它不是独立一段反应伤害，这点和剧变完全不同。

为什么我堆了精通数字没涨多少？

精通加成是乘区，且增幅公式（2.78/1400）在低精通段涨幅平缓。主 C 主要收益还是双爆和攻击力，精通是锦上添花。

融化只能火主 C 打吗？

不是。火打冰是 2 倍（胡桃），冰打火是 1.5 倍。想让谁吃 2 倍，就按"火打冰"的顺序安排。

蒸发融化能暴击吗？

能。这是它和剧变最直观的区别——剧变一律不暴击，增幅可以。

小结

蒸发融化是给高面板主 C用的最强单段倍率：2 倍版本喂主 C 一次高倍攻击，再吃一层精通乘区。记住两件事就够——强元素触发给 2 倍，以及它吃的是主 C 面板、可以暴击。配队时把顺序摆对，数字差 25%。
