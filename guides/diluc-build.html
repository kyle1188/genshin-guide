原神迪卢克（Diluc）配队与圣遗物：5 星火系双手剑主C·炽烈魔女增伤机制

快速答案

  • 迪卢克是 5 星火系双手剑（蒙德晨曦酒庄主人「暗火骑士」），站场主C，核心输出 = 元素爆发「黎明」火附魔 + 三段战技 + 普攻/下落。
  • 核心圣遗物：炽烈的炎之魔女 4pc（2pc 火伤 +15%，4pc 施放元素战技后火伤 +37.5% 叠 3 层 10s，几乎常驻）。
  • 主词条：攻击力沙 / 火伤杯 / 双爆头。
  • 副词条：双爆 > 攻击 > 精通（蒸发队保留 1–2 条）> 充能（无班尼特 120–130%，有班尼特 100–115%）。
  • 特点：爆发火附魔期内所有普攻/重击/下落都变火伤；蒸发队（水主挂水）＞融化队（冰），登龙斩（下落）吃万叶/闲云增伤。
  • 最佳配队：迪卢克+行秋/夜兰+班尼特+万叶（蒸发）、迪卢克+凯亚/罗莎莉亚+班尼特+钟离（融化）。
  • 武器「狼的末路」最稳；F2P 锻造「试作古华」，4 星「螭骨剑」（需护盾角色保层）。

角色机制

迪卢克的核心循环是「爆发挂火 → 附魔期高倍率输出」：

  • 元素爆发「黎明」：范围火伤 + 烈焰附魔（固有天赋 A4 延长 4s 并加 20% 火伤），附魔期普攻/重击/下落全部变火伤。
  • 元素战技「逆焰之刃」：可连续施放 3 次，高倍率短冷却，是炽烈魔女 4pc 叠层核心（每段叠 +12.5% 火伤）。
  • 下落攻击（登龙斩：普攻/战技命中瞬间冲刺跳）：大倍率单体，配合万叶扩散减抗 / 闲云下落增伤，是近年迪卢克输出大头。
  • 因此主堆攻击 + 双爆、火伤杯；蒸发队补少量精通（80–120）即可。

配队

蒸发队（最稳定）

迪卢克 + 行秋/夜兰（挂水）+ 班尼特（加攻回血）+ 万叶（聚怪减抗）

  • 行秋 Q 持续挂水 + 迪卢克 E 三段 + 下落 → 高频蒸发，万叶减火/水抗放大反应。
  • 班尼特 Q 铺火领域加攻，迪卢克站场吃满。

融化队（高倍率单体）

迪卢克 + 凯亚/罗莎莉亚（挂冰）+ 班尼特 + 钟离（护盾/减物抗）

  • 凯亚后台挂冰 + 迪卢克打融化，钟离护盾保站场环境。
  • 适合深渊特定层 / 单体 Boss。

命座优先级

  • C1：对 50% 血量以上敌人火伤 +15%——常驻增伤，性价比最高。
  • C4：战技后 25% 概率追加一段额外火伤（条件触发，不追）。
  • C6：施放战技后普攻攻速提升、下落/普攻增伤——输出质变，真爱目标。

FAQ

迪卢克现在版本还强吗？

强。蒸发队依然是 T0 稳定输出，登龙斩（下落）吃万叶/闲云增伤后上限更高，不靠机制花活，吃的是双爆与反应。

迪卢克毕业武器是哪把？

最稳「狼的末路」；没 5 星就锻造「试作古华」过渡、有 BP 拿「螭骨剑」（配钟离护盾防掉层）。

迪卢克走蒸发还是融化？

蒸发更稳（行秋/夜兰持续挂水，蒸发系数高）；融化倍率高但吃拐冰附着，适合凯亚/罗莎莉亚+钟离。

迪卢克充能要多少？

爆发 80 点。有班尼特 100–115%，无班尼特 120–130%。

迪卢克 C1 值得追吗？

值得。C1 对 50% 血量以上敌人 +15% 火伤是常驻增伤，比 C4 的条件增伤实用得多。
