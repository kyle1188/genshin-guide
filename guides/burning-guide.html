原神燃烧反应详解：0.25 倍系数、DoT 持续伤害与真实用途

燃烧是草与火相遇时的剧变反应，也是所有剧变反应里系数最低的一档（0.25）。它伤害不高，却被反复问"到底有没有用"。这篇把触发、DoT 节奏、精通换算和它真正的三个用途讲清楚。

快速答案
  • 草打火、火打草都能触发，目标进入燃烧状态，持续掉火元素血。
  • 每 0.27 秒结算一次（约每秒 3-4 跳），伤害 = 0.25 × 等级系数 ×（1 + 精通加成），90 级零精通单跳 361。
  • 持续时间取决于草元素附着量——草烧完就停，补草能续。
  • 目标燃烧期间一直带火元素，可以顺手触发蒸发、融化。
  • 只吃等级、精通、目标火抗；不吃暴击、不吃攻击力、无视防御。
  • 真实定位不是输出，而是持续挂火 + 磨血 + 破盾的辅助手段。

一、触发与持续：谁烧谁

草与火相遇即燃烧，顺序无关：

  • 火打已附着草的目标；
  • 草打已附着火的目标。

触发后目标进入燃烧状态，每 0.27 秒结算一次火元素 DoT。状态靠"燃元素"维持，只消耗草的附着量——草烧完状态即消失，重新补草可以立刻续上。所以持续时长不看你挂火多快，看的是草元素还能撑多久。

二、伤害公式与等级系数

燃烧伤害 = 0.25 × 等级系数 ×（1 + 精通加成）× 目标火抗倍率。90 级等级系数约 1446，所以零精通单跳就是 0.25 × 1446 ≈ 361。

三、精通加成走哪套公式

燃烧是剧变反应，精通加成用 16 × 精通 ÷（精通 + 2000） 这一套。前 200 点精通就拿到约 +96%，性价比很高；往上收益放缓。所以纯燃烧流把精通堆到 400 左右通常够用，再高就边际递减。

要特别区分：燃烧吃的精通加成和增幅反应（蒸发/融化）吃的不是一套系数。增幅走的是 2.78 × 精通 ÷（精通 + 1400）。同一层精通，喂给燃烧和喂给蒸发，涨幅不一样。

四、燃烧的三个真实用途

1. 持续挂火

目标在燃烧期间一直带火元素附着。这对水、冰主 C 很关键：随时能吃到蒸发、融化。它相当于一个"挂火 buff"，比单个火技能更稳定。这是燃烧最实用的价值。

2. 磨血与清杂

虽然单跳低，但燃烧是 持续、对群、无冷却 的。清理成堆小怪或在 BOSS 战里叠火抗窗口时，它提供的是"顺便掉血"，不是主力。多目标场景下，燃烧同时点多个怪，总伤才显出价值。

3. 破盾

火元素对冰盾有克制，持续燃烧能慢慢磨掉冰盾。遇到冰盾精英，让目标保持燃烧比硬砸一下更快磨盾。

五、常见误区

误区一：燃烧是输出主力

不是。0.25 倍系数是所有剧变里最低的，堆到 1000 精通单跳也就 1,490。它做不了主 C 的伤害来源，定位是辅助。

误区二：燃烧需要堆双爆

完全无效。剧变反应不吃暴击率、暴击伤害、攻击力。给燃烧触发者堆双爆是白养。

误区三：断火就永远停了

不会。只要目标身上还有草（或重新补草），补一次火就能重新点燃。真正停掉的时机是草的附着量耗尽且没补。

六、配队思路

  • 主 C 是水或冰：燃烧持续挂火，主 C 全程能吃蒸发/融化，这是燃烧队最常见形态。
  • 高频挂草：纳西妲、柯莱、提纳里这类后台稳定挂草的角色，能保证燃烧不断档。
  • 高频挂火：香菱、班尼特、宵宫，负责持续点火。
  • 组合起来就是"草火双挂 + 水/冰主 C 吃增幅"，燃烧本身提供稳定的火附着层。

七、常见问题

燃烧伤害高吗？

不高，是所有剧变里最低的（0.25×）。它的价值在持续挂火和磨血，不在单次数值。

燃烧持续多久？

取决于草元素附着量。烧完即停，补草可续。没有固定 8 秒上限，别被"燃烧 8 秒"的说法带偏。

燃烧吃减抗吗？

吃。燃烧是火元素反应，任何火元素减抗都会放大它，和所有火系反应一样。

燃烧能不能暴击？

不能。剧变反应一律不暴击，只看等级、精通、减抗。

燃烧对群划算吗？

划算。同时对多个目标挂火掉血，是它少数能打的场景；对单目标基本可以忽略。

小结

燃烧是"系数最低、用途最多"的反应。别指望它的伤害，要它的稳定挂火层：让水冰主 C 白捡蒸发融化，顺带磨血破盾。想打高反应伤害，去看超绽放和超载；想挂火配合增幅，燃烧才是对的工具。
