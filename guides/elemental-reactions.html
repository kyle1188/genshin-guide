原神元素反应详解 2026：增幅 / 剧变 / 草系全机制

原神一大半伤害来自反应。本篇把 7 元素与全部反应讲清楚：哪类反应乘区、哪类看精通、草系怎么玩，帮你从「乱按技能」变成「规划反应链」。

七元素速览

火 Pyro 火

高频反应源，蒸发、融化、燃烧都靠它，输出队核心。

水 Hydro 水

蒸发、冻结、绽放的挂水端，行秋 / 夜兰是常驻。

雷 Electro 雷

感电、超导、激化，脱手副 C（菲谢尔）最爱。

冰 Cryo 冰

冻结、碎冰、融化，控制与爆发兼得。

风 Anemo 风

扩散（Swirl）聚怪减抗，万叶 / 砂糖是万能配件。

岩 Geo 岩

结晶护盾，钟离提供全游戏最强减抗护盾。

草 Dendro 草

燃烧、绽放、激化，后期主流反应族。

触发原理：同一敌人身上先挂 A 元素（aura），再用 B 元素触发（trigger）。应用顺序 often 决定倍率与反应类型。

反应两大族

增幅反应（Amplifying）：直接乘算你这一击的伤害，吃攻击力、双暴与元素精通——蒸发、融化属于这类。
剧变反应（Transformative）：造成独立的固定伤害，不吃攻击力，只看角色等级与元素精通——超载、超导、感电、扩散、结晶、碎冰，以及整个草系族都属此类。

增幅反应：蒸发 / 融化

反应触发顺序倍率
蒸发 Vaporize火打水（Pyro → Hydro）1.5×
蒸发 Vaporize水打火（Hydro → Pyro）2.0×
融化 Melt冰打火（Cryo → Pyro）1.5×
融化 Melt火打冰（Pyro → Cryo）2.0×

让伤害最高那一击当触发器，吃满 2.0×。元素精通会在这个倍率区上再抬一截。

剧变反应

超载 Overload

火 + 雷，AoE 火伤并把小怪击飞，挖矿好用。

超导 Superconduct

冰 + 雷，AoE 冰伤并大幅降物理抗性，物理队必备。

感电 Electro-Charged

水 + 雷，对潮湿敌人持续跳电，群怪强。

扩散 Swirl

风 + 其他，把该元素扩散给周围并减抗，聚怪神技。

结晶 Crystallize

岩 + 其他，掉落对应元素护盾，钟离招牌。

碎冰 Shatter

重击 / 大剑砸冻结敌人，附加物理伤害。

草系反应（Dendro 家族）

草 + 火 = 燃烧（持续火伤）；草 + 水 = 绽放 生成草原核；草原核 + 雷 = 超绽放（追踪弹，强）；草原核 + 火 = 烈绽放（大范围 AoE）；草 + 雷 = 激化 上状态后，雷触发 = 超激化、草触发 = 蔓激化。草系全族吃元素精通，是后期主流。

元素精通与配队原理

元素精通（EM）做两件事：对增幅反应提升倍率区；对剧变与草系反应直接加伤。纯物理 / 暴击主 C 几乎不需要它。一个能打的队伍通常是：挂元素者（aura） + 触发者（trigger，用大数字那一击） + 风系聚怪 / 减抗 + 奶 / 盾保命。

圣遗物与词条怎么堆

增幅队（蒸发 / 融化）：主 C 堆双暴、攻击 %、对应元素伤害，精通只是副产物。剧变 / 草系队（绽放、激化、超绽放）：触发者直接堆元素精通与等级，攻击力反而不重要。具体套装见 圣遗物刷取优先级。

快速问答

蒸发和融化的倍率分别是多少？

蒸发：火打水 1.5×、水打火 2.0×；融化：冰打火 1.5×、火打冰 2.0×。让伤害最高那一击当触发器拿 2.0×，元素精通再抬倍率区。

元素精通到底有什么用？

对增幅反应提升倍率区；对剧变和草系反应直接加伤。纯物理或暴击主 C 几乎不需要它。

新手优先练哪种反应队？

蒸发队（行秋 + 任意火 C）或绽放 / 超绽放队（草 + 水 + 雷）门槛低、收益高，最适合开荒。

草元素反应和老反应有什么不同？

草系引入草原核与激化状态，衍生超绽放、烈绽放、超激化，是后期主流且吃元素精通，和老剧变体系思路不同。
