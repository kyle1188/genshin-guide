原神可莉（Klee）配队与圣遗物：5 星火系法器主C·炽烈魔女增伤机制

快速答案

  • 可莉是 5 星火系法器（蒙德西风骑士团「火花骑士」），站场主C，核心输出 = 蹦蹦炸弹持续挂火 + 重击/普攻高频火伤。
  • 核心圣遗物：炽烈的炎之魔女 4pc（2pc 火伤 +15%，4pc 蒸发/融化增伤 +15% 且战技后火伤叠加），配合芙宁娜可换逐影猎人 4pc。
  • 主词条：攻击力沙 / 火伤杯 / 双爆头。
  • 副词条：双爆 > 攻击 > 精通（反应队）> 充能（爆发仅 60 点，110–130% 足够）。
  • 特点：伤害几乎全为火；蒸发队（水主挂水）最稳，融化队吃冰附着，纯火队堆双爆。
  • 最佳配队：可莉+行秋/夜兰+班尼特+万叶（蒸发）、可莉+迪奥娜/凯亚+班尼特+万叶（融化）。
  • 武器「四风原典」最稳（暴击率+移速+叠层元素增伤）；F2P 用「嘟嘟可故事集」或「匣里日月」。

角色机制

可莉的输出靠「持续挂火 + 站场爆发」：

  • 元素战技「蹦蹦炸弹」：投掷后弹跳 3 次并留下 8 颗诡雷，全程高频火附着，是炽烈魔女 4pc 叠层与蒸发/融化触发核心。
  • 元素爆发「轰轰火花」：10s 内自动索敌火花，全队火伤 +15%，耗能仅 60 点，循环压力小。
  • 固有天赋「砰砰礼物」：普攻/蹦蹦炸弹造成伤害时有 50% 概率获得「炸裂火花」，下次重击免体力且 +50% 伤害——重击是可莉大头输出。
  • 因此主堆攻击 + 双爆、火伤杯；反应队保留少量精通。

配队

蒸发队（最稳定）

可莉 + 行秋/夜兰（挂水）+ 班尼特（加攻回血）+ 万叶（聚怪减抗）

  • 行秋/夜兰持续挂水 + 可莉重击 → 高频蒸发，万叶扩散减火/水抗放大反应。
  • 班尼特 Q 铺火领域加攻，可莉站场吃满。

融化队（高倍率）

可莉 + 迪奥娜/凯亚（挂冰）+ 班尼特 + 万叶

  • 迪奥娜/凯亚后台挂冰 + 可莉打融化，适合冰环境或单体。

纯火队

可莉 + 香菱 + 班尼特 + 万叶

  • 双火共鸣 + 香菱脱手火，纯火堆双爆，简单粗暴。

命座优先级

  • C2：蹦蹦炸弹与诡雷命中后降低敌人 23% 防御 12s——最大提升，性价比最高，建议停在 C2。
  • C4：释放爆发后全队攻速/移速提升——转火更灵活。
  • C6：持续挂火且自产能量，真爱可追。

FAQ

可莉现在版本还值得练吗？

值得。蒸发队依然好用，配合芙宁娜+逐影猎人上限更高；缺点是身板脆、动画长，需要护盾/治疗保命。

可莉毕业武器是哪把？

最稳「四风原典」（暴击率+移速+叠层元素增伤）；没有 5 星可用「流浪乐章」（精5爆发高）或活动武器「嘟嘟可故事集」。

可莉走蒸发还是融化？

蒸发更稳（行秋/夜兰持续挂水），融化倍率高但吃冰附着、对单更优。

可莉充能要多少？

元素爆发仅 60 点，有班尼特 110–130% 足够，无需堆太高。

可莉 C2 值得追吗？

值得。C2 减敌 23% 防御是稳定增伤，是性价比最高的命座，建议抽到 C2 即可。
