资源怎么投

顺序：班尼特（加攻 + 奶，最优先）→ 行秋 / 香菱脱手副 C → 菲谢尔 → 再补体系四星。四幻神尽量拉到关键命座（班尼特 1 命、香菱 4 命、菲谢尔 6 命质变）。辅助不用堆双暴，堆对应核心属性（充能、精通、生命）即可。

常见坑

  • 盲目升天赋：部分四星辅助增伤靠固有天赋，战斗天赋 1 级足够（如布伦妮），别浪费天赋材料。
  • 主 C 优先陷阱：开荒期先练脱手副 C / 辅助（班尼特、行秋）比硬练四星主 C 收益更高。
  • 忽视充能：香菱、行秋靠大招吃饭，充能不够循环断档，伤害暴跌。

快速问答

四星必练哪四个？

班尼特、行秋、香菱、菲谢尔。零命即强、泛用封顶，是所有配队的地基。

没有五星能打通深渊吗？

能。四幻神 + 体系四星组成国家队、激化队、超绽放队，零氪也能满进度。

四星主 C 推荐谁？

雷泽（开荒站场）、烟绯（火法过渡）可用，但优先级低于脱手副 C 与辅助。

新手资源先给谁？

班尼特最优先（加攻 + 奶），其次行秋、香菱这类脱手副 C。
