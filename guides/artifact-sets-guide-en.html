Best Genshin Artifact Sets 2026: Pick by Role, Not by Rarity

Artifacts are the #1 power variable on any character. Know which set fits which role and whether to run 2-pc or 4-pc before dumping resin into a domain — that beats blind farming.

Pick by role first, set second: Main DPS wants damage sets, Sub-DPS wants burst/reaction sets, Support wants team buffs. The same set on the wrong unit is wasted. Layers below: universal → per-element → reaction/support.

2-pc vs 4-pc: How to Decide

  • Always 4-pc: effects that need the 4-pc trigger (Emblem, VV, Deepwood, Flower, Marechaussee, Husk).
  • 2+2 is safer: when you just want two stat lines (e.g. ATK% + elemental DMG%), mixing two 2-pc sets often beats a forced 4-pc.
  • Main stat > set: a correct Crit / elemental-DMG main stat matters more than completing a 4-pc with garbage substats.

Resin Efficiency

New players: farm the Emblem domain (also drops exp) and the VV domain first — near-universal value. Then fill element gaps by your main team. Don't open three new domains at once; focus one until your carry is built. Use 4-star pieces from chests before AR45; 5-star only becomes guaranteed at AR45.

Quick Answers

How do I choose artifact sets?

Start from role: Main DPS uses the matching elemental-damage set or Marechaussee / Golden Troupe, Sub-DPS uses Emblem or Golden Troupe, Support uses Noblesse / Tenacity / VV. The same set on the wrong unit is wasted — match the kit, not the rarity.

Is 2-pc or 4-pc better?

Run 4-pc when the bonus needs the 4-pc trigger (Emblem, VV, Deepwood, Flower, Marechaussee, Husk). When you only want two stat lines, a 2+2 mix is often safer. A correct main stat beats forcing a 4-pc with bad substats.

Which domain should a beginner farm?

Emblem domain (also drops exp) and VV domain first — almost everyone needs them and resin efficiency is highest. Then fill element gaps for your main team. Use 4-star pieces before AR45; 5-star is only guaranteed at AR45.

What main stats do I pick?

Flower is fixed HP, Plume fixed ATK. Sands: DPS ATK%/EM, support ER%/HP%. Goblet: elemental DMG%. Circlet: DPS CRIT Rate/DMG, support ER%/Healing. DPS substats chase CRIT Rate:CRIT DMG ≈ 1:2.
