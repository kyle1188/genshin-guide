原神防御与抗性机制详解：为什么你的伤害被吃掉一半

很多人花一周刷圣遗物拉双暴，却发现伤害没长多少——因为真正吃伤害的是防御与抗性这两个你从来不看的数字。这篇讲清两个乘区的公式、减防与减抗的来源、上限与怪物基础抗性，以及配队时该选哪一个。

  • 防御乘区怎么算？ （角色等级+100）÷（角色等级+100 + （敌人等级+100）×（1−减防）×（1−无视防御））。
  • 同等级下打多少折？ 对同等级敌人，无减防时只有约 16.7%的伤害系数（Lv90 敌人 DEF 约 950）。
  • 减防上限？ 硬上限 90%，堆再多也不多算。
  • 抗性怎么算？ 三层：RES<0 时 1−RES/2；0≤RES<75% 时 1−RES；RES≥75% 时 1÷（4×RES+1）。
  • 减抗越多越好吗？ 负值区只按一半效果算，例如 10% 物抗遇上超导−40%，最终只提升约 27.8% 伤害。

防御乘区：你的伤害先被砍掉八成

伤害公式里，防御乘区（DEF Multiplier）是独立一块，公式为：

防御乘区 = （角色等级+100）÷ [ （角色等级+100） + （敌人等级+100）× k ]，其中 k = (1−减防) × (1−无视防御)。

  • 敌人防御值 = 5 × 敌人等级 + 500；Lv90 敌人防御约 950。
  • 无任何减防时，Lv90 打 Lv90：190 ÷ (190+950) ≈ 16.7%——即你的理论伤害先被砍到不到两成。
  • 防御乘区跟等级相关而非血量，所以高难内容等级压制非常明显。

关键理解：减防把 k 变小，从而提高伤害；而无视防御是另一层，与减防相乘而非相加，两者叠加效果更好。

减防来源与 90% 上限

多个减防来源相加，但总额硬封顶 90%：

例：丽莎 15% + 可莱 23% + 雷泽 15% = 53%，远未触顶。实测多个减防叠满后伤害不再增长，所以不要为了堆减防而放弃更好的搅局角色。

抗性（RES）：三层公式与负值陷阱

抗性独立按伤害类型（物理/火/水/雷/冰/岩/风/草）分别计算：

总 RES = 基础 RES + 额外 RES − 减抗

区间伤害乘数说明
RES < 01 − RES/2负抗仍加伤，但只按一半算
0 ≤ RES < 75%1 − RES常规区间，一分抗性换一分伤害
RES ≥ 75%1 ÷ (4×RES + 1)严重递减，堆再高收益溡薄

经典例子：10% 物抗敌人遇上超导（−40% 物抗）→ 最终 −30% → 乘数 = 1−(−0.30/2) = 1.15。原本是 0.90，实际提升约 27.8%，而不是看起来的 40%。

这就是“负抗性只算一半”的实际含义：减抗仍值得堆，但越接近负区边界边际收益越低。

实战组合示例（物理队）：超导 −40% 物抗 + 钟离盾 −20% 全抗 → 对 10% 物抗敌人最终 −50%，乘数 1.25。这就是为什么物理 DPS 队里几乎必带冰雷一人 + 钟离。

怪物基础抗性速查

  • 大多数普通怪：单元素约 10%（例如普通丘丘人）。
  • 丘丘暴徒：物抗约 30%，元素抗仅约 10%——物理队打丘丘暴徒会明显发虚。
  • 深渊使徒 / 传令官：对自身元素抗性极高（常 50%+ ），盾在时甚至免疫，先破盾再说。
  • 无相之物 / 史莱姆 / 漂浮灵：对本元素免疫或高抗，别用同元素硬打。
  • 古岩龙晰：开战时随机锁定一种元素抗性，被击倒后解除。
  • 深渊与活动 Boss：在基础抗性上额外叠加，这是减抗角色在高难环境价值暴涨的原因。

经验法则：目标越“肉”，说明你正在被隐藏抗性吃伤害，一个减抗工具人的价值就越高。

减防 vs 减抗：配队该选哪个

维度减防（DEF Shred）减抗（RES Shred）
作用范围全类型通用指定伤害类型
上限90% 硬封顶无上限，但负区只算一半
叠加方式同类相加同类相加
与其他乘区乘算（独立乘区）乘算（独立乘区）
典型使用高练度队、周本、深渊 12 层单元素队、反应队、物理队

实用建议：

  • 一般队伍只需一个强力减抗工具人（风系 40% 或钟离 20%）就够。
  • 单元素主 C 队：优先风套 4 件套（凯亚/万叶/绋人），免费 40% 是全游性价比最高的减抗。
  • 物理队：超导几乎必备，再搭钟离盾叠到 −50%。
  • 反应队：剧变反应（超激化/燃烧等）只受抗性影响、不吃减防，减抗优先级更高。
  • 高难深渊：防御与抗性双高，两类减益叠加性价最高。

常见坑

  • 以为减抗按字面加伤：负区只算一半，−40% 物抗实际只提升 27.8%。
  • 对已高抗目标堆减抗：甲级不按比例，高抗性时每点减抗收益更大。
  • 忽视无视防御：它与减防相乘，两者都有时收益更高。
  • 用同元素打免疫怪：无相之物、漂浮灵对本元素免疫，换元素或换人。
  • 只堆减防不堆减抗：单元素队对高抗怪物时，减抗比减防更立竿见影。

小结

伤害不够不一定是圣遗物不行，很可能是你在向防御与抗性交税。同等级下防御先吃掉八成，减防上限 90%，减抗负值只按一半算。一般队伍带一个风套 4 件套或钟离就够；物理队加超导；反应队优先减抗。把这两个乘区理清，你会发现同一套面板能打出完全不同的伤害。
