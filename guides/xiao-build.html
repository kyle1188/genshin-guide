原神魈配装攻略 2026：武器、圣遗物、配队与下落攻击主C

当前热点 · 原神 7.0 至冬（Snezhnaya）（8 月 12 日上线）

7.0 至冬即将往卡池灌入一堆新冰/雷角色——但能过终局的账号，依然是那些有自洽主C的。魈正是如此：一个风系下落主C，不挑任何特定队友就能运作，所以无论 7.0 环境怎么变他都不掉队。趁大家追新角色，现在养魈给你一个永久、不挑队的DPS，能塞进几乎任何队伍。本篇讲清他的最佳武器、4 件套辰砂往生录、攻击% / 风伤 / 双暴属性目标、保住下落窗口的充能，以及魈主C壳。

魈是原神招牌的风系下落主C。他的元素爆发（靖妖傩舞）让他变成高空下落攻击手，造成巨额群体风伤、代价是自己的血量。他是风系的「自私主C」——配一个盾（钟离）加一个充能（班尼特）就能清场。本篇讲清他的最佳武器（和璞鸢·贯虹之槊 vs 护摩之杖 / 决斗之枪）、4 件套辰砂往生录、攻击% / 风伤 / 双暴属性目标、保住大招的充能，以及与钟离 / 班尼特 / 芙宁娜 / 枫原万叶 的配队。

说明：魈的机制、辰砂偏好、下落玩法属于长期稳定的核心玩法，不随版本大改。上面的 7.0 卡池提示只是引流备注，不是配装变化——下面的攻略无论卡池如何都成立。

为什么值得养魈

在风系单位里，只有魈给你一个纯粹、自洽的主C，不依赖特定队友也能发光。

  • 不挑队主C：他大招让他成为伤害源；配谁给盾+增益都行，永不被环境淘汰。
  • 巨额下落群清：他大招下落反复砸周围敌人——深渊群怪最佳清场。
  • 血换设计：他牺牲自己血量而非脆皮配置，与钟离盾完美契合。
  • 常青价值：一个从上线起就扛过每个版本的风系DPS——安全的长期投资。
养对的魈是风系的「自私主C」：指群、开大、看它消失。想要一个永不过时的主C，就是他。

最佳武器

魈要攻击%、双暴与高基础攻击。他用长柄武器。

专武 ★和璞鸢·贯虹之槊

最强 · 5★ 长柄

他的专武：高基础攻击 + 命中叠攻击% 被动，长下落连段滚雪球。有就是清楚最强。

获取：武器池

5★护摩之杖

最高个人伤害

生命转攻 + 低血增伤——魈大招期间在低血，被动常驻。PJWS 之后裸伤最强。

获取：武器池

4★决斗之枪

纪行最优

大额暴击率 + 被围时攻击% 增益（下落时永远被围）。对他最强的平民友好 4★。

获取：珍珠之歌

3★白缨枪（R5）

免费预算选

高额普攻加成（R5）——而魈下落算普攻。最好的免费武器；精炼后稀有度之上。

获取：商店 / 祈愿（3★）

最佳圣遗物

对下落主C魈，4 件套辰砂往生录最佳——它大招后叠攻击%，为他整套机制量身定做。

套装适用场景原因
辰砂往生录（4件）默认下落主C+18% 攻击 + 大招后最多 +48% 攻击——他的本命套装，窗口期免费巨大跳伤。
2 翠绿之影 + 2 攻击% 18%灵活 / 无辰砂件风套减风抗 + 裸攻击；辰砂件弱时强、灵活。
2 追忆 + 2 角斗通用攻击堆叠安全全能，无套装依赖地增他普攻/下落伤害。
4 追忆少开大时用大招换普攻增伤——仅当你循环少用大招（少见）。

属性目标——攻击优先，再风伤，再双暴（加一点充能）

魈的下落伤害吃攻击%与双暴；他大招成本高，一点充能%保住窗口。

主流配队

魈的队伍共享一条规则：给他盾、增攻击、充能大招，然后让他下落。

主C壳魈 + 钟离 + 班尼特

常青核心

钟离盾 + 班尼特攻击增益 + 灵活（芙宁娜 / 琴 / 珉）。最稳、最高伤的魈壳——肉且宽容。

最全能魈队

芙宁娜核心魈 + 芙宁娜

fanfare 增伤

芙宁娜叠 fanfare 转成巨额全队增伤，她后台水配一个治疗。魈最现代的强队之一。

高端当前环境壳

风系魈 + 万叶 / 珉

风减抗 + 充能

枫原万叶（或珉）减风抗聚怪；珉也给魈大招充能。加伤害与舒适。

对群强

双岩魈 + 钟离 + 岩

耐久下落壳

魈 + 钟离 + 岩灵活（阿贝多 / 凝光）吃岩共鸣 +生命% / 对护盾敌人 +15% 伤害。肉且自洽。

天赋优先级

按这个顺序升级——普攻击落、战技给跳、大招开窗口：

  1. 普通攻击（卷积微尘）→ 9–13。下落吃普攻等级；这是他的伤害。先皇冠。
  2. 元素爆发（靖妖傩舞）→ 8–10。延长下落窗口增下落伤害；普攻之后升。
  3. 元素战技（风轮两立）→ 6–8。小跳 + 核弹；为机动与能量，非核心伤害。

命座——C1 与 C2 最关键

魈命座曲线前置：早命修掉最大痛点。

  • C1（坏劫·勘破）：额外空中冲刺 + 减下落伤害——更顺、更长的下落循环。
  • C2（坏劫·吞恨）：增战技跳跃次数并转成大招能量——真正的充能与伤害提升。
  • C4（坏劫·护身）：大招内用战技后 +暴击率——平滑暴击下限。
  • C6（坏劫·降魔）：下落命中生成小真空刃——巨大个人DPS跃升。氪佬终点。
关键规则：C0 已是顶级下落主C；C1/C2 是现实甜点（若主练他）。因为他是限定五星，除非魈是你本命，否则 C2 停手。

常见误区

  • 跳过充能。无约 120–140% 充能，他大招掉线、啥也干不了。充能是多数新魈忽略的属性。
  • 无盾。魈大招烧自己血，无钟离 / 迪奥娜盾会自杀。盾是必需。
  • 圣遗物错配。没有辰砂的随意 2+2 丢了大招后攻击叠加。辰砂 4 件是默认有原因。
  • 错堆精通或攻击杯。他要风伤杯与攻击沙——他不反应，精通无用。

还没抽到魈

他是限定五星，周期复刻，所以复刻时抽——而 7.0 至冬重塑阵容，现在锁一个不挑队友的主C是最安全的长期打法。等待期间，枫原万叶或某个下落友好的四星能解馋，但都没有魈的自洽主C力。把钟离与班尼特和他一起养；三者风+岩+火是带多数账号过终局的耐久主C骨架，而现在正是 7.0 变动前最安全的常青抽取。
