Genshin Rerun Schedule: How Often Characters Rerun & Primogem Plan

"Should I wait for the rerun?" is the question before every pull: if you can wait, saving Primogems is the cheaper path; if you cannot, you pay up in the current patch. This guide turns rerun timing into arithmetic - intervals by character type, the Archon rotation, the last few banners, and a F2P saving schedule - so you budget by version rhythm instead of gambling.

  • Rerun frequency: 84% of limited 5-stars have rerun at least once; the average interval is about 7.5 versions.
  • Regular vs Archons: regular limiteds ~10-12 versions (1-1.5 years); Archons ~6-9 versions (about 9 months) in a strict rotation.
  • F2P wait time: ~4-6 months to cover the C0 average cost (12,160 Primogems); 2-3 months with Welkin Moon.

Rerun Intervals: Three Rhythms by Character Type

Every version lasts 6 weeks (42 days), with two ~2-week banner phases. Observed rerun intervals fall into three tiers (stats from bannerhistory.app covering 1.0-7.2, 61 limited 5-stars, plus community tracking):

Three usable patterns: 1. The first rerun is fast - new characters rerun in 3-6 versions while demand is high, then settle into 10-12. 2. Archons rotate in launch order (Venti → Zhongli → Raiden Shogun → Nahida → Furina), rarely out of order. 3. Reruns ride the patch theme - when a patch adds a region or mechanic for an element, that Archon tends to rerun early (Nahida in the Sumeru era, Furina before the Natlan transition).

Primogem Saving Math (F2P View)

Site-wide baseline: F2P earns ~2,000-3,000 Primogems/month (dailies + events); the C0 average cost is 12,160 (soft pity ~76 pulls) and the worst case 28,800 (lost 50/50 + 90-pull hard pity, about $360 without first-purchase double).

Usage: last rerun version + 10-12 versions = next rerun window (±1 version). If the window is inside 4-6 months and you are F2P, waiting pays. If the character launched less than 3 months ago (its first fast rerun window has not arrived yet), pull now instead of waiting.

Common Mistakes

  • "Reruns are free" - No. Reruns still run 50/50 plus soft/hard pity; the cost equals a new banner. What you save is the opportunity cost of missing the current patch.
  • "Waiting makes it cheaper" - No. 1,600 Primogems per ~$0.80 does not drop. You save by not spending this patch, not by a price cut.
  • "Archons rerun back to back" - They do not. The rotation holds 6-9 versions between Archons, and no two consecutive versions feature the same Archon.

Bottom Line

In one line: regular limiteds return every 10-12 versions, Archons every 6-9 in launch order, and a F2P saves enough for one soft pity in 4-6 months (2-3 with Welkin). Check official banner announcements before the window; if it lands inside 4-6 months, save and wait - pull new characters in the current patch instead. That is the simplest model that turns "wait for the rerun" from a gamble into arithmetic.
