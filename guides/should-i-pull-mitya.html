原神米提亚值得抽吗：7.2 命座与 F2P 决策

结论：账号有冰系就抽，没有就先攒等复刻。米提亚是 7.2 上线的 5★雷系法器主C，伤害全靠「星超导」反应（冰+雷），没有冰系队友输出直接减半。C0 完整可满星，C1 质变（信标 4→5、前台暴伤 +40%）；C2 进入副C成型区。保 1 个平均约 12,160 原石，最坏 28,800（≈$360）。

快速决策

  • 值不值：有冰系（奥黛特/八重/冰旅行者在队）→ 抽；没有 → 攒钻等复刻，C0 可满星不亏。
  • 命座值不值：C1 质变（主C上限翻倍），C2 副C成型；预算紧保 C0，重氪上 C2。
  • F2P 该不该抽：该。零成本队「米提亚 + 冰旅行者 + 阿廖沙 + 砂糖」0 命成型。
  • 抽谁：缺主C选米提亚；缺后台增伤/挂水选同池复刻芙宁娜（共享 pity）。

值不值：米提亚 vs 同池芙宁娜

7.2 第一阶段米提亚（新）与芙宁娜（复刻）两个卡池共享一套 pity 与 50/50，抽数互通。选谁看账号短板：

维度米提亚（新 5★雷）芙宁娜（复刻 5★水）
定位站场主C / 后台副C，星超导聚爆后台增伤辅助 + 副C，最高 75% 全队增伤
核心依赖必须冰系队友（火不行）必须带治疗（叠气氛值）
缺什么就抽他缺雷主C、想玩超导/星超导队缺后台拐、蒸发/永冻/绽放队增伤
0 命可用度可满星，C1 质变可满星，机制完整
优先级有冰系 → 优先没拐 → 优先

一句话：两队都成型、资源紧张时，抽你缺的那一类——有冰系抽米提亚（新角色强度更高），缺后台增伤抽芙宁娜（复刻但泛用性极强）。

F2P 该不该抽

该抽——米提亚的 F2P 队几乎零成本：

关键数字：站场流充能 140%（双雷）/120%（三雷，1 命后）；EM 500 吃满全队 14% 增伤。0 命 + 冰旅行者就能打满星，是 F2P 主C 里门槛最低的一档。
