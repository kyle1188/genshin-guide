原神角色突破材料攻略：元素宝石、Boss 材料与完整清单

突破材料是练角色的第一道门槛，也是最容易被低估的资源黑洞：一个角色从 1 级到 90 级，光特产就要 168 个、摩拉 42 万。这篇攻略把突破材料拆成四类讲清，附六阶段完整需求表与七元素宝石对照，帮你把树脂花在刀刃上。

  • 突破要几类材料？ 四类：元素宝石 + 普通怪掉落 + 地区特产 + 世界 Boss 材料，外加摩拉。
  • 满突破 1→90 要多少？ 宝石四档共 1/9/9/6，特产 168 个，普通怪掉落三档共 84 个，Boss 材料 46 个，摩拉 42 万。
  • 元素宝石有哪四档？ Sliver → Fragment → Chunk → Gemstone，需求随阶段递增，总量固定。
  • 宝石去哪刷？ 世界 Boss 与周本 Boss 都会掉，每种宝石对应一种元素，挑「缺宝石 + 缺 Boss 材料」重合的那只打最划算。

突破材料分四类，外加摩拉

不管什么角色，突破吃的东西结构完全一样，只是具体物品随元素与角色替换。四类材料 + 摩拉：

元素宝石：七元素一表对照

宝石是突破的核心货币，分四档：Sliver → Fragment → Chunk → Gemstone，需求量随阶段递增，总量恒定为 1/9/9/6。

各类材料怎么刷最省树脂

  • 元素宝石：刷世界 Boss。每只 Boss 固定掉某一种元素宝石，同时掉自己的专属材料；周本 Boss 也掉宝石。缺宝石时优先挑「你要的宝石 + 你要的 Boss 材料」重合的那只打。
  • 世界 Boss 材料：打指定 Boss，每次 2-3 个，40 树脂一次。满 46 个约需 15-23 次。
  • 普通怪掉落：用讨伐手册追踪，一趟路线连打同系列怪，效率远高于零散刷。
  • 地区特产：野外采集，48 小时刷新，不消耗树脂，属于「顺手做」的资源。
  • 摩拉：地脉·藏金之花是最稳定的来源，缺钱时优先刷它。

别漏了天赋材料

突破之外，天赋升级还要吃：天赋书（Teaching / Guide / Philosophies）+ 怪物掉落 + 周本 Boss 材料 + 皇冠（Crown of Insight）。单个天赋练到 10 级约需 165 万摩拉，三个天赋全满接近 500 万摩拉再加 3 个皇冠。

所以刷周本时有个技巧：优先选「天赋材料」和「突破宝石」都缺的那一个，一次投入两份收益。

常见坑

  • 备齐材料却忘摩拉：42 万摩拉不是小数，刷材料时顺手刷地脉。
  • 只留高档宝石：Sliver 与 Fragment 低等级阶段必需，别当废物合成掉。
  • 以为特产每天刷新：48 小时一轮，隔天再跑是白跑。
  • 乱刷 Boss：不针对缺的材料刷，树脂全打水漂。
  • 忽略天赋：突破只是解锁上限，天赋等级才是伤害的大头。

小结

突破材料的核心是一张清单 + 一个优先级：四类材料（宝石 / 怪掉落 / 特产 / Boss 材料）加摩拉，满突破总量固定为 1/9/9/6 + 84 + 168 + 46 + 42 万。先确定要养的角色，按清单缺什么刷什么，周本挑「天赋材料与宝石都缺」的那只，80→90 视资源决定要不要冲。
