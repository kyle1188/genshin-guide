原神Prune（普鲁涅）Build攻略：4★风法器聚怪精通辅助

Prune（普鲁涅）是 6.6 版本（Luna VII）上线的 4★风元素法器，来自挪德卡莱的猎巫人，早期泄漏名 Prydwen。定位是聚怪 + 元素精通 utility：翠绿之影做副C、教官做精通辅助，流浪乐章性价比最高。

快速答案

  • 定位：风系聚怪 + 精通辅助 / 副C。
  • 武器：流浪乐章（Song of the Lonely Moon）＞ 四风原典 ＞ 天空之卷。
  • 圣遗物：翠绿之影 4pc（副C）/ 教官 4pc（辅助）。
  • 主词条：精通沙 + 风伤杯/精通杯 + 精通头。
  • 配队：Prune + 香菱 + 班尼特 + 钟离/芙宁娜。

Prune 是谁

Prune（普鲁涅）是 6.6 版本（Luna VII）上线的 4★风元素法器角色，来自挪德卡莱（Nod-Krai）的猎巫人，早期泄漏名 Prydwen 即指向她。定位是聚怪 + 元素精通 utility 型风系副C/辅助，风元素伤害 + 扩散减抗，能替一队补足元素精通与聚怪。

套装效果适用

主词条：精通沙 + 风伤杯（副C）或 精通杯（辅助）+ 精通头；副词条 精通 > 暴率 > 生命。

天赋升级顺序

元素战技（E）≈ 元素爆发（Q）> 普攻。E 是聚怪 + 风伤核心，Q 提供扩散减抗窗口，普攻占比低可最后升。

最佳配队

队伍成员要点
聚怪蒸发队香菱 + Prune + 班尼特 + 钟离/芙宁娜Prune 扩散减抗 40%，香菱蒸发主C
激化副C柯莱 + Prune + 白术 + 钟离精通双拐 + 风伤副C
月系通用Prune + 任意月主C + 充能 + 生存补聚怪 + 精通 utility 位

是否值得抽

有现成风系辅助（砂糖/万叶）可跳；缺聚怪 + 精通拐且不想抽 5★ 辅助时，Prune 是低成本高性价比的 4★ 解法。C0 完整可用，不依赖命座。
