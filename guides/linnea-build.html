原神莉奈娅Build指南：6.5岩系弓辅助

莉奈娅是 6.5 上线的 5★岩系弓月结晶核心拐，伤害与治疗全吃防御力。毕业面板：DEF 2000+、暴击 60–70%、暴伤 150%+；BiS 专武「黄金霜缚誓弦」（88.2%暴伤副词条）+ 圣遗物「晨月牧曲」4pc。0命即完整可用，C2 为全队水岩暴伤质变。

快速答案

  • 定位：后台辅助/副C，月结晶体系核心拐。
  • 武器：黄金霜缚誓弦（5★专武）＞西风猎弓/夹钩（4★）＞弹弓（F2P）。
  • 圣遗物：晨月牧曲 4pc（首选）/ 绸月夜曲 4pc / 金厄梦醒之遗 4pc。
  • 主词条：DEF沙漏 + DEF/岩伤杯 + 暴击头。
  • 配队：Zibai + 莉奈娅 + 科隆比娜 + Illuga（顶配）。

莉奈娅是谁

莉奈娅是 6.5 版本推出的 5★岩系弓角色，月结晶体系的核心辅助。她的伤害和治疗都依赖防御力，通过技能将普通结晶转化为月结晶，提供减抗（最高 30%）、精通增益（基于自身 DEF 的 5%）和全队治疗。90 级基础 DEF 907 为岩系之最，突破属性再给 24.2% 暴击率。

命座分析

  • C0：完整可用——减抗、精通、治疗、后台输出 4 件套全有
  • C1：战技/月笼谐奏获层数，消耗提升全队月结晶伤害

  • C6：拉满 C1 层数并提升消耗倍率，附带队友月结晶增伤
