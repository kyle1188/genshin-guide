原神结晶反应攻略：结晶护盾盾量公式、吸收效率与实战用法

结晶是原神里唯一会「掉东西」的元素反应：它不掉血，掉的是护盾。但它的盾量由谁决定、精通到底加多少、为什么它可以和角色护盾共存——这些细节几乎没人讲清。这篇一次说明白。

快速答案
  • 结晶 = 岩元素 + 火 / 水 / 冰 / 雷（岩不能附着，只能当触发元素），本身不造成伤害
  • 掉落对应元素的晶片，拾取后获得同元素护盾；晶片与护盾各存在 15 秒
  • 同一时刻只能存在一个结晶护盾，再拾取会覆盖旧的
  • 盾量 = 基础盾量（由触发岩角色的等级决定）×（1 + 精通加成）；90 级基础 1,851，精通 200 加 55.5%
  • 元素结晶盾对同元素伤害有 250% 吸收（只吃 40%）；岩系护盾对所有伤害 150%
  • 护盾强效（如双岩共鸣 +15%）减的是「护盾受到的伤害」，不是加盾量
  • 多个护盾共存时，伤害会同时扣每一个盾

结晶反应：岩 + 四大元素，掉盾不掉血

当岩元素攻击命中已经附着火、水、冰、雷的目标时触发结晶。岩元素本身无法附着在敌人身上，所以它永远只能当「触发元素」，不能当「被触发元素」——这也意味着结晶不能由岩 + 岩产生。

反应不造成任何伤害，而是在目标脚下掉出一枚对应元素的晶片。拾取后获得一层同元素护盾。

项目数值 / 规则

晶片持续15 秒（场上最多 3 枚，超出后最旧的约 2 秒后消失）

注意两个限制：攻击「环境元素」不会产生结晶（打水面、感电水、燃烧的草堆都不行，因为岩元素没打到实体）；另外晶片不能被敌人拾取。

盾量怎么算

结晶盾的盾量由两部分决定：

盾量 = 基础盾量（按触发岩角色的等级）×（1 + 精通加成）

基础盾量只看触发结晶的那名岩系角色的等级，与攻击力、防御力、生命值都无关：

精通加成按公式 4.44 × EM ÷ (EM + 1400) 计算，收益很快饱和：

结论：300 精通以内性价比很高（盾量已 +78%），再往上收益明显变缓。对以结晶盾为辅助手段的队伍，300 精通左右是比较舒服的目标；不建议为了盾量硬堆到 800+。

250% 与 150%：吸收效率才是关键

盾量只是「血量」，真正决定能抗多少的是吸收效率：

护盾类型对同元素伤害对其他伤害
元素结晶盾（火 / 水 / 冰 / 雷）250%（只吃 40%）100%
岩系护盾（幼岩龙蜥晶片）150%150%
角色技能护盾（钟离、迪奥娜、诺艾尔等）由技能定义，多为「对应元素 250%」或「全伤害 150%」

所以面对火伤敌人时，捡一枚火结晶盾，等于盾量凭空变成 2.5 倍——这才是结晶盾的正确用法。反过来，捡错元素的盾去打对应敌人，效率就是 100%，非常吃亏。

岩系护盾（由幼岩龙蜥、纯岩原盘等产出）属于独立体系，不与结晶盾互相覆盖，可以同时存在。

多盾共存会怎样

很多人以为「多套盾叠加 = 盾更厚」，其实机制是：

  • 受到伤害时，每一个护盾会被同时扣除相同的伤害值；
  • 实际保护量约等于最厚的那一个盾，而不是相加；
  • 所以叠盾的真实收益是「多一层保险」，而不是「血量翻倍」。

不过多盾确实有实用价值：结晶盾薄、容易碎，但角色技能盾通常在冷却中；两层盾能显著减少空窗期。

护盾强效到底加什么

这是最常被误解的一条：护盾强效不是加盾量。

它的作用是：减少「当前场上角色身上的护盾」所受到的伤害。也就是说，盾量还是那么多，只是每次挨打扣得更少。例子：一个能抗 1000 伤害的盾，在 21% 减伤（如行秋雨帘剑）加持下，只被扣 790 点盾值。

  • 护盾强效只对当前场上角色生效，换人即失效；
  • 双岩共鸣提供约 +15% 护盾强效，对全队护盾都有意义；
  • 因为它是减伤性质，越薄的盾收益越明显——正好补结晶盾「薄」的短板。

实战定位：结晶盾更适合当「顺手的额外一层」——队伍里有岩系角色时，打附着元素敌人就能顺手捡盾；但不要指望它替代专职护盾角色。

什么时候值得专门吃结晶盾

  1. 敌人伤害类型明确时。面对火法、水法、雷史莱姆这类单一元素输出，捡对应元素盾效率是 250%。
  2. 岩系角色在场时顺路捡。不必刻意改配队，岩系打反应顺手会掉晶片。
  3. 缺一个「防秒杀」缓冲。在深渊高层被一套连招压血线时，一层结晶盾常常就是生与死的差别。
  4. 配合护盾强效。双岩共鸣 + 结晶盾的组合能把一层薄盾的实际承伤能力拉高一个档次。

冷知识：冻结状态的结晶优先级

被冻结的目标吃到岩元素攻击时，碎冰的优先级高于结晶。如果冻结状态下还有「藏元素」（未完全消耗的水/冰），碎冰解除冻结后剩余藏元素才会与岩形成结晶，掉出对应元素的盾。所以「岩打冻住的水环境敌人」经常能顺手拿到一枚水结晶盾。

另外，感电状态（雷水共存）下，元素优先级为雷 > 水，因此只会与雷反应生成雷结晶盾，水元素会残留在敌人头上。
