原神元素共鸣详解 2026：七元素队伍加成怎么选

元素共鸣是「白送」的常驻全队增益：只要四人队里有两名同元素，整队立刻吃 buff。选对共鸣，比多练一只角色还实在。

共鸣是常驻白送 buff：四人队里只要有两个同元素，全队立刻获得被动增益，无需触发、无需站场。四人均不同元素则触发「保护性庇护」而不是元素共鸣。

七种元素共鸣一览

共鸣触发全队效果
热诚之火（火）2 火+25% 攻击力
流水之盾（水）2 水+25% 生命上限
碎冰之锋（冰）2 冰对冻结 / 冰附着敌人 +15% 暴击率
强能之雷（雷）2 雷剧变反应 100% 产 1 枚雷微粒（5s CD），缓解全队充能
迅风之羽（风）2 风体力 -15%、移速 +10%、技能 CD -5%
磐石之固（岩）2 岩护盾强效 +15%；护盾下 +15% 伤害、敌人岩抗 -20%
蔓生翠野（草）2 草基础精通 +50；触发草反应后再 +30 / +20 精通

每种共鸣还会缩短某一种元素附着在你身上的持续时间（如减抗干扰），但实战价值主要看上面的核心数值。

四异元素：保护性庇护

当四名角色元素各不相同，不触发任何元素共鸣，改为获得保护性庇护：全队元素抗性 +15%、物理抗性 +15%。生存向但亏输出，一般只在需要硬扛时用。

怎么选共鸣

火共鸣最泛用

直接 +25% 攻击，物理与反应队通吃，几乎任何主 C 队都能塞第二个火（班尼特 / 香菱）。

水共鸣给血量 C

那维莱特、夜兰、胡桃、珊瑚宫心海靠生命上限吃收益，双水力提升明显。

冰共鸣配冻结

神里绫华、甘雨冻结队白嫖 15% 暴击，圣遗物暴击压力骤减。

雷共鸣管充能

雷电将军、北斗等重爆发后，雷微粒让全队循环更顺。

常见误区

  • 以为要站场才生效：只要编入四人队即生效，后台角色也算。
  • 盲目追火共鸣：草反应队该用草共鸣叠精通，冻结队该用冰共鸣，别为了攻击牺牲体系。
  • 四异色当万能：保护性庇护只加抗，输出队基本不选。

快速问答

元素共鸣怎么触发？

四人队伍中有两名及以上同元素角色即自动触发，全队获得常驻增益，不要求站场。四人均不同元素则触发保护性庇护而非元素共鸣。

哪个元素共鸣最强？

火共鸣（+25% 攻击）最泛用，物理与反应队都吃；但具体选哪个要看队伍缺什么——血量 C 用水、冻结队用冰、草反应队用草、充能紧张的雷队用雷。

双水共鸣值得吗？

非常值得，尤其那维莱特、夜兰、胡桃、心海这类吃生命上限的角色，双水直接 +25% 生命，约等于多一件生命沙。

四异元素有什么用？

四名角色元素各不相同会触发保护性庇护：全队元素抗性与物理抗性各 +15%，偏生存，输出队一般不选。
