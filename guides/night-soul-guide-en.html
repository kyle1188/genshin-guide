Genshin Nightsoul System Explained: Natlan's Exclusive Buff

Quick Answer

  • What is the Nightsoul system: A survival + buff system introduced in Natlan (5.0); every Natlan character has a "Nightsoul" passive.
  • Core mechanic: With at least one Natlan character on field, the whole party gains a Nightsoul value that decays over time; the higher the value, the more cooldown reduction on Elemental Skill / Burst.
  • How to gain it: Defeat specific enemies, complete environment puzzles, or pick up Nightsoul Crystals to restore Nightsoul.
  • Build impact: Natlan main DPS should prioritize ER to keep their skill loop; supports rely on Nightsoul to trigger extra effects.

Nightsoul Base Mechanics

Nightsoul is a combat buff system unique to the Natlan region, implemented starting with version 5.0. Unlike traditional elemental reactions, it is a team-wide passive buff that does not need to be actively triggered — it is maintained automatically over time.

Core Properties of the Nightsoul Value

  • Form: Exists as a value within the party, capped at 100 points
  • Natural decay: Decays about 0.5–1 points per second (varies with combat intensity)
  • Buff effect: At each threshold of 20/40/60/80/100 points, it grants different cooldown reduction and damage bonuses
  • Duration: Leaving the Natlan region temporarily disables the system; it reactivates upon entering a new area

How the Nightsoul System Affects Character Builds

The Nightsoul value directly affects skill and Burst cooldowns, so different characters focus on different build priorities:

For Main DPS

  • ER: Prioritize keeping the Elemental Burst loop; higher Nightsoul shortens cooldowns faster, but base ER is still the foundation
  • Crit: Nightsoul buffs don't raise damage multipliers directly, so pursue output stats as normal
  • Recommended weapon: A 5-star weapon that provides ER or boosts the Elemental Burst

For Supports

  • Energy loop: Make sure you can frequently cast the Elemental Skill to trigger Nightsoul-related effects
  • Healing / shield: Under Nightsoul the party is more forgiving, but basic survivability is still needed

Common Misconceptions

  • Misconception 1: Nightsoul is an independent resource bar — It is actually a hidden value, not shown in the UI; judge it via buff icons
  • Misconception 2: Every character depends on Nightsoul — Non-Natlan characters only get the global bonus, not the Natlan-exclusive interactions
  • Misconception 3: Nightsoul can stack infinitely — It is capped at 100 points, and using skills in combat drains it faster

Related Questions

How do I gain Nightsoul?

Defeating special Natlan enemies, completing environment puzzles, and picking up Nightsoul Crystals all restore the Nightsoul value.

Does the Nightsoul value decay over time?

Yes. It decays continuously; using skills in combat accelerates the drain, but it naturally recovers a bit in safe zones.

Are non-Natlan characters affected by the Nightsoul system?

Yes. As long as at least one Natlan character is in the party, the whole team benefits from the Nightsoul bonus.

How is Nightsoul related to Elemental Resonance?

They are independent. Nightsoul is a Natlan-exclusive system, while Elemental Resonance is a global system.
