原神基尼奇Build指南：5.0草系双手剑燃烧输出

基尼奇是 5.0 版本上线的 5★草系双手剑站场主C，伤害全吃攻击力与双爆，通过元素战技进入「夜魂加护 Nightsoul's Blessing」状态挂绳循环，让敌人处于燃烧或超绽放状态可最快充能夜魂值、打出龙炮。毕业面板：攻击力 2000+、暴率约 60%（黑曜秘典自带 +40%）、暴伤 200%+、充能 130%。0 命完整可用，C1/C2 质变（+12.6% / +32%）。

快速答案

  • 定位：站场主C，夜魂加护状态技能+龙炮倍率，靠燃烧/超绽放充能。
  • 武器：山脊之王之牙（5★专武）＞苇海信标/炽沙千日（5★）＞螭骨剑/大地之契（4★ F2P）。
  • 圣遗物：黑曜秘典 4pc（首选）/ 未竟幻想曲 4pc（燃烧队）。
  • 主词条：攻击力沙 + 草伤杯 + 暴击头。
  • 配队：基尼奇 + 香菱 + 班尼特 + 希诺宁/芙宁娜（燃烧队）。

基尼奇是谁

基尼奇是 5.0 版本推出的 5★草系双手剑角色，纳塔希图兹兰（Huitztlan）的猎龙人，称号「Turnfire Hunt」。他用钩索技能挂绳进入「夜魂加护」，在此状态下普攻变为循环射击（Loop Shot，按技能倍率结算并回 3 点夜魂值），夜魂值攒满后放出龙炮（Scalespiker Cannon）打一次高倍草伤。天赋「荒原的代价 A1」让他挂在敌人上的敌人在触发燃烧/超绽放时，每 0.8 秒回 7 点夜魂值——所以有后台火系/水系挂元素的队友时他充能最快、输出最高。

天赋升级顺序

元素战技 ＞ 元素爆发 ＞ 普通攻击。基尼奇核心伤害来自夜魂加护下的龙炮与循环射击（均按技能/大招倍率结算），优先拉满元素战技，其次大招；普攻倍率低，最后升。
