原神白术配装攻略 2026：武器、圣遗物、配队与草系盾奶

当前热点 · 原神 6.7 下半（持续至 2026-08-11）

这是 7.0 至冬（Snezhnaya）版本（8 月 12 日上线）之前的最后一个卡池窗口——雷电将军与科罗莎琳娜（Columbina）正在复刻。如果你在补全能扛住深渊的阵容，常青草系核心是 纳西妲 + 白术：白术是盾奶引擎，让纳西妲的绽放与激化队无需任何切人。把他养对——足够生命值撑盾、足够充能每轮开大、穿上深林的记忆——他就能做你草系队伍多年的锚点。本篇正是讲这个。

白术——璃月行走的药庐——是原神里最舒服的草系盾奶。他的战技落下护盾跟随当前角色并定时治疗；元素爆发打出协同草伤的同时给全队回血。他不需要站场，这让他成为最容易塞进绽放、超绽放、激化核心的生存位。本篇讲清他的最佳武器（碧落之珑 vs 试作金珀 / 讨龙英杰谭）、4 件套深林的记忆、约 130% 充能目标、为什么 C2 是真提升，以及和纳西妲 / 行秋 / 雷电将军 / 班尼特 的配队。

说明：白术的机制、深林偏好、约 130% 充能目标属于长期稳定的核心玩法，不随版本大改。上面的 6.7 卡池提示只是引流备注，不是配装变化——下面的攻略无论卡池如何都成立。

为什么值得养白术

在草系辅助里，只有白术能在零站场下把盾 + 治疗打包给你。如果你跑纳西妲队，他是默认舒适度首选。

  • 通用盾 + 治疗：战技（太素诊列）召唤无缝护盾跟随当前角色，脉冲时治疗——防小怪蹭血，也防深渊腐蚀。
  • 无需站场：他做的事全在后台，绝不抢主C循环里的秒数。丢进去就忘了他。
  • 草系触发器：爆发通过协同攻击挂草，免切人喂饱绽放 / 超绽放 / 激化 / 蔓生。
  • 全队生命缩放：C2 时他的治疗吃最大生命，爆发还给全队增益，是安静的倍率放大器。
养对的白术能把脆皮纳西妲绽放队变成自循环引擎。对草系核心而言，他是游戏里最省事的生存位。

最佳武器

白术要生命%（撑盾/治疗强度），若武器不给充能也喜欢元素充能。他用法器。

专武 ★碧落之珑

最强 · 5★ 法器（专武）

他的专武：生命% 主词条，被动在战技后给充能并放大自身伤害。最干净「穿上就忘」的选项——一次解决充能与缩放。

获取：武器池

4★试作金珀

锻造回能 + 治疗工具

锻造免费：被动在白术放大招时回能并治疗全队，顺手解决充能还加一层治疗。对他而言最好的平民武器，甩其他一条街。

获取：锻造（珊瑚枝）

3★讨龙英杰谭

预算增益选

讨龙（R5）给下一位角色大额攻击%buff——若只把他当纯触发器、想抬主C，很强。无充能，注意回能。

获取：祈愿（便宜）

替代白辰之环 / 祭礼残章

反应向选项

白辰之环给雷/草伤（激化/蔓生队）；祭礼残章给精通（绽放/蔓生）。仅当你是特定反应壳且充能已覆盖时才用。

获取：锻造 / 祈愿

最佳圣遗物

对几乎所有白术，4 件套深林的记忆最佳——它的草抗削减抬全队草伤，2 件套生命% 喂他的盾与治疗。若别人已带深林，拆成 2+2 组合。

套装适用场景原因
深林的记忆（4件）默认 / 唯一草草抗削减 + 2 件套生命%。他的本命套装——除非队友更需这个槽位，否则穿它。
2 深林 + 2 千岩牢固别人带深林时保留深林生命%，同时加全队攻击/护盾buff。减抗被覆盖时全能。
2 深林 + 2 少女/海染砗磲纯治疗壳在肉度高的绽放队里，纯保命时更多治疗量。
2 深林 + 2 生命%好词条紧张缺第三套时，堆生命% 是安全填充——盾与治疗都吃它。

属性目标——生命优先，再堆充能

白术的盾与治疗吃最大生命，所以生命% 主导装备。充能是唯一要盯的另一项：达标后再猛堆生命%。

位置主词条副词条优先级
时之沙生命%（治疗build绝不选精通/攻击）生命% > 充能%（到约130%）> 精通（绽放/蔓生队）> 双暴（仅建个人伤害时）

按武器的充能目标：用碧落之珑或试作金珀 ≈ 120–130% 充能 足够；用讨龙或无充能武器 ≈ 推到 140%+ 充能 并靠副词条。没达标，他的大招（协同草 + 治疗）进冷却——这是白术头号失败。

主流配队

白术的队伍共享一条规则：配草系驱动器（纳西妲）+ 反应触发器，然后让核心干活。

绽放纳西妲绽放

顶级草系核心

纳西妲 + 白术 + 行秋（水）+ 灵活（久岐忍/雷神超绽放）。白术帮队伍挡绽放自伤并保命，纳西妲触发种子。旗舰草系队。

最全能草系壳

超绽放雷神超绽放

雷触发变体

纳西妲 + 白术 + 雷电将军 + 行秋。雷神技能把绽放种子转成超绽放；白术前扛腐蚀、后治蹭血。巨额群清。

对群强

激化蔓生激化

单体变体

纳西妲 + 白术 + 雷系主C（雷神/久岐忍/菲谢尔）+ 灵活。白术后台草维持激化 aura，盾奶让主C保持侵略。干净打 boss。

对 boss 强

蔓生火系蔓生

灵活反应壳

纳西妲 + 白术 + 火系触发器（香菱 / 胡桃）+ 班尼特。蔓生打在火伤上，白术保全场。比严格蒸发/融化更宽容、更肉。

宽容且肉

天赋优先级

按这个顺序升级——战技驱动盾/治疗，爆发驱动草 + 治疗：

  1. 元素战技（太素诊列）→ 8–13。无缝护盾强度与治疗在此缩放。能皇冠先皇冠。
  2. 元素爆发（愈气全形）→ 8–13。协同草伤与全队治疗在此。战技之后升它。
  3. 普通攻击 → 1–6。除整活切人外几乎不攻击。保持低。

命座——C2 是真提升

白术命座曲线前置：一个命座明显变强，之后一路顺。

  • C1（悬壶济尘）：协同攻击多打一次，初盾更强。不错，非必需。
  • C2（斡旋阴阳）：治疗吃最大生命，爆发还增益全队——这是大头。C2 约等于把他的生存与安静增幅价值翻倍。主草系值得追。
  • C4：延长无缝护盾并加少量协同攻击伤害。明显一档。
  • C6（养生主理）：受他爆发增益的角色额外打草伤——封顶他的主C辅助价值。奢侈，非必需。
关键规则：C0 已是顶级生存；拿到 C2 就停。C2 是白术从「好奶」跨到「最强草系触发器」的分水岭。C6 是奢侈。

常见误区

  • 充能太低。白术头号杀手。无充能武器却低于 120% 充能 = 大招变冷却——无协同草、无全队治疗，绽放队丢触发器。
  • 把他当输出养。他的活是盾 + 治疗 + 后台草。堆裸伤害/双暴浪费槽位——生命% 与充能赢。
  • 圣遗物错配。没有深林的随意 2+2 丢了草抗削减与生命%。深林 4 件是默认有原因。
  • 为纯奶跳过他。芭芭拉 / 七七数字更高但不给盾且需站场。白术的盾 + 免切便利才是纳西妲队偏爱他的原因。

还没抽到白术

他是限定五星，要在复刻抽——而 6.7 下半窗口是 7.0 至冬重塑卡池日历前你最后的机会。等待期间，瑶瑶 或 绮良良 能临时补后台草 + 治疗，单纳西妲 也能驱动绽放——但都没有白术的无缝护盾加免切便利。把纳西妲与行秋和他一起养；三者组成带多数账号通关深渊的草系核心，而现在正是 7.0 变动前最安全的常青抽取。

快速问答

白术最佳配装是什么？

白术走草系盾奶路线，圣遗物首选4件套深林的记忆（草抗削减+2件套生命%），主词条堆生命%，充能达标约130%。他无需站场，是绽放、超绽放、激化队最轻松的生存位。

白术最佳武器？

碧落之珑（Jadefall's Splendor）是他的五星专武，生命%主词条且放大技能与充能。最强国民选择是锻造的试作金珀（回能+治疗），以及讨龙英杰谭（R5 给下位攻击%buff）。

白术充能需要多少？

用碧落之珑或试作金珀约 120–130% 充能足矣；用讨龙或无机充能武器需推到 140%+。没达标大招进冷却，协同草与全队治疗都断——这是白术头号失败原因。

白术值得抽吗？

值得。他是唯一盾奶一体且零站场的草系辅助，纳西妲队默认舒适度首选。C0 已是顶级生存，C2 让他从好奶变成最强草系触发器。
