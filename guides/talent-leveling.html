原神天赋升级优先级 2026：技能、爆发、普攻先点谁

天赋是角色伤害的上限。点错顺序=白砸摩拉和树脂。先搞清谁该点、点几级，比盲目三冠重要得多。

6 级是性价比拐点：单天赋 1→6 级只要约 12.25 万摩拉、几本绿蓝书；7 级以上成本陡增（7 级 12 万、8 级 26 万、9 级 45 万、10 级 70 万）。辅助和副 C 点到 6-8 级通常就够，把皇冠和树脂留给主 C。

升级顺序：按定位来

主 C

爆发 > 元素战技 > 普攻。例外：胡桃、刻晴（重击）、神里绫华、甘雨（蓄力）要把普攻也点高；依赖普攻输出的主 C 普攻优先。

副 C / 速切

只点爆发和战技到 8-10 级，普攻通常不点。香菱、行秋、夜兰这类靠大招打输出的，爆发拉满。

辅助 / 奶妈

只点提供增益的那一两个技能到 6-8 级即可。班尼特点满大招（治疗 + 攻击 buff），普攻不用动。

皇冠给谁

皇冠是稀缺资源：只来自限时大活动或神樱 / 雪山等常驻树，一个版本往往就一两个。只给真爱或核心主 C 的三冠，别撒胡椒面。三冠一个角色要 3 皇冠加约 496 万摩拉，是终局投入。

常见坑

  • 盲目三冠：不是每个角色都值得。先把主 C 关键天赋点到 9-10，辅助停在 6-8 级更划算。
  • 给辅助点普攻：班尼特、行秋的普攻几乎不贡献输出，点它是纯浪费。
  • 忽视天赋书星期：每种书只在一周 3 天开放，错过要等；用炼金台把低级书合高级书补缺口。
  • 忘了升角色等级：天赋再高，角色 80 级没突破也会卡上限；只有 HP / 防御 / 精通主 C 才需要冲 90 级。

快速问答

天赋先点哪个？

主 C 一般爆发 > 战技 > 普攻；靠普攻输出的（胡桃、神里、甘雨、刻晴重击）普攻也要高。副 C 只点爆发和战技，辅助只点增益技能到 6-8 级。

天赋升到几级够用？

辅助和副 C 6-8 级通常就够，性价比最高；主 C 关键天赋建议 9-10 级。单天赋 1→6 只要约 12 万摩拉，7 级以上成本陡增。

皇冠给谁最值？

只给真爱或核心主 C。皇冠只来自限时活动和常驻树，一个版本就一两个；三冠一个角色要 3 皇冠加约 496 万摩拉，是终局投入。

天赋书怎么刷高效？

每种书只在一周 3 天开放，按表规划树脂；用炼金台把 3 本低级合成 1 本高级补缺口；周本材料是硬时间锁，提前攒。
