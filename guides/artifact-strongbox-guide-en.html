Genshin Artifact Strongbox Guide: 3-to-1 Exchange, Rules and Best Sets

Quick Answer

  • Where: any Crafting Bench → Mystic Offering, unlocked at Adventure Rank 45.
  • Rate: 3 five-star artifacts → 1 random five-star of the set you pick. Slot, main stat and substats are all random.
  • Batch: up to 39 inputs at once, which yields 13 artifacts.
  • Cost: zero Resin. Only five-star artifacts qualify; four-star pieces cannot be used.
  • Hard rule: a leveled artifact loses every point of invested EXP and Mora, with no refund.

How the Artifact Strongbox Actually Works

The Artifact Strongbox is the output of Mystic Offering, a crafting-bench recipe. You sacrifice five-star artifacts and get back one five-star artifact from a set you pick. Nothing about the result is controllable — slot, main stat and every substat are rolled fresh. What you are buying is extra rolls on a specific set without spending Resin.

Because the Resin cost is zero, the Strongbox competes with artifact domains only on opportunity cost, never on Resin. That single fact is what decides when to use it.

Which Sets Are Worth Converting

The test is not "is this set good". It is "is the set it shares a domain with useless to me". A domain that drops two sets you both want is efficient to farm; a domain that drops one good set and one dead set is exactly what the Strongbox exists for.

The Mistake That Costs Millions of Mora

Never feed a leveled artifact into Mystic Offering. A +20 piece carries roughly 270,000 EXP worth of investment. Submit it and every point of that EXP and every Mora spent on it disappears — the recipe returns no refund, no partial credit, nothing. Lock your good pieces before you open the bench, and filter to level-0 artifacts only.

The same trap applies in reverse: artifacts you have not leveled are the correct fuel. Sorting your inventory by "level 0, five-star" gives you a clean fuel pool in one click.

Step by Step

  1. Lock every artifact you might equip — Elemental DMG goblets, CRIT Rate and CRIT DMG circlets, EM pieces.
  2. Go to any Crafting Bench and open the Mystic Offering tab.
  3. Pick the set you want from the strongbox list.
  4. Select level-0 five-star artifacts in multiples of three, up to 39.
  5. Confirm — one random five-star of that set arrives per three inputs.

Available sets grow every version, so check the list in-game rather than relying on an old guide: recent versions have added strongboxes for sets that originally had none.

When the Strongbox Beats Resin

  • You are gearing a support, not a carry. Supports mostly need the 4pc bonus, so a random-but-correct set usually beats a perfect-stat wrong set.
  • Your fuel pile is growing. Hundreds of unused five-star pieces are dead inventory; converting them is pure upside.
  • The target set's domain is a trap. Any set paired with a dead partner qualifies.
  • You are below AR 45 with artifact ambitions. Wait — five-star drops are not guaranteed before AR 45, and Mystic Offering is locked anyway.
What is the exchange rate of the Genshin Artifact Strongbox?

Three five-star artifacts become one random five-star artifact from the set you select. The ratio is fixed at 3:1, only five-star artifacts can be used as fuel, and up to 39 can be submitted at once for 13 results.

Does Mystic Offering cost Resin?

No. It costs zero Resin. The real cost is the artifacts you feed in - any EXP and Mora invested in a leveled piece is lost permanently with no refund.

Which artifact set should I target first?

Target a set whose domain partner is useless to you. Viridescent Venerer, Noblesse Oblige, Tenacity of the Millelith and Crimson Witch of Flames are the classic four, because Maiden Beloved, Bloodstained Chivalry, Pale Flame and Lavawalker rarely serve a roster.

Can I choose the slot or main stat from a Strongbox?

No. Slot, main stat and all substats are random. The only choice you make is which set the box belongs to, so treat it as buying extra rolls rather than crafting a specific piece.
