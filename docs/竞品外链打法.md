# 竞品外链打法（存底）

> 创建：2026-11-23 ｜ 关联：`外链提交清单v1.md`（11-14 竞品结论）、`M3-AI双轨验收-11-20.md`（不追外链定调）

## 0. 方法边界（先钉死）

- **站长视角只能看到「出站信号」**（他往外引了什么），**看不到入链清单**（谁往他引了外链）。
- 入链反查必须用 Ahrefs / SEMrush / Moz；免费额度有限（Semrush 免费版每视图限 10 词，优先打关键词差距）。
- 入链数字（如 game8 DR76 / 17.36K 引链域）全部来自反查工具，不是站内能看的。

## 1. 出站信号 5 判读点（通用方法）

| 看哪里 | 读出什么 | 对应打法 |
|---|---|---|
| 正文引用谁 | 服气/互引的权威源 | 互链、投稿 |
| footer / about / 资源页 | 有无 links / partner / resources 页 | 外链交换、资源列表 |
| 联盟标识（rel=sponsored、?aff=、Amazon） | 靠联盟变现 | 外链目的=引流量吃分成 |
| 投稿痕迹（"投稿于 xx"） | guest post | 内容型外链 |
| schema/结构化数据密度 | 内容权威性 | AI/Google 偏爱引用 |

## 2. 实证：bannerhistory.app（2026-11-23 抓取）

**信号盘点：**
- 正文外链：**0 条**（无导航/引用/资源指向他站）
- 唯一出站：图片资源 `enka.network`（角色头像）、`cdn.jsdelivr.net/gh/Mar-7th/StarRailRes`（星铁图标）——借图床，非引荐
- affiliate / partner / sponsored / Patreon / resources 页：**全无**
- 联盟追踪参数：**无**

**打法判定：「工具被引」型，不刷 DR**
- 不做链接交换、不投 guest post、不做资源矩阵页
- 把卡池历史做成结构化数据 + 干净统计页 → **让别站（含本站）主动引数据** → 白赚引链域
- 实证：本站 `banner-rerun-guide` 写「复刻间隔统计来自 bannerhistory.app」= 本站主动送给它一条引用链
